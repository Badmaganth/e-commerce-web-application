# E-Commerce Web Application

This is a full-stack e-commerce web application I developed using the MERN stack. The project helped me understand how a frontend, backend, and database work together to build a web application.

## Technologies Used

- React.js for the frontend
- Node.js and Express.js for the backend
- MongoDB for the database
- Mongoose for database operations
- Redux Toolkit for state management
- JWT for authentication
- bcrypt for password hashing

## Features

- User authentication using JWT
- Secure password hashing using bcrypt
- Product management
- Product search and filtering
- Shopping cart operations
- Order processing
- REST APIs for communication between frontend and backend

## How It Works

The frontend is built using React.js, where users interact with the application. The backend uses Node.js and Express.js to handle requests and process application logic. MongoDB is used to store the application data, and Mongoose helps interact with the database.

I used REST APIs to connect the frontend and backend. Redux Toolkit is used to manage application state, and JWT-based authentication helps protect routes that require an authenticated user.

## Running the Project

### Prerequisites

- Node.js and npm
- MongoDB or a MongoDB Atlas account
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/Badmaganth/e-commerce-web-application.git
cd e-commerce-web-application
```

Install the frontend and backend dependencies using the instructions and folder names in the project.

```bash
cd frontend
npm install
```

In a separate terminal, install the backend dependencies:

```bash
cd backend
npm install
```

Configure the required environment variables for the database connection and authentication according to the backend code.

Start the frontend and backend using the scripts defined in their respective `package.json` files.
